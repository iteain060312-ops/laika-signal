# LAIKA SIGNAL — 라이카시네마 감상 신호 챗봇

영화를 예매한 관객에게 라이카시네마 카카오톡 채널이 예매 안내를 보내고,
상영이 끝나면 감상을 '신호'로 보내보라고 안내한다.
감상을 보내면 AI가 키워드를 골라 아레시보 메시지 같은 픽셀 문양으로 바꾸고,
신호를 우주로 보내면 두 개의 신호가 도착한다.

시연 흐름: 예매 안내(영화·좌석 무작위) → 5초 뒤 자동으로 상영 종료 + 신호 설명과 감상 요청
→ 감상 입력 → 신호 이미지 + "이 신호를 우주로 보낼까요?" → 우주로 보내기
→ 30초 뒤 신호 2개 자동 도착 (받은 신호에 ♡ 좋아요 → 보낸 사람에게 마음 도착 알림) → 이후 같은 영화에 새 신호가 오면 틈틈이 알림('이 영화 신호 그만 받기' 가능)
→ 한 바퀴가 끝나면 아래 버튼으로 '📡 일상 속 신호 받기'(비슷한 신호 → 다른 신호 → 좋아요 순서로 도착)나 '🎟 새로 예매하기'를 골라 계속 체험

- **같은 영화, 낯선 신호**: 같은 영화를 보고 다른 키워드를 느낀 관객의 감상
- **다른 영화, 닮은 신호**: 다른 영화를 보고 비슷한 키워드를 느낀 관객의 감상

---

## 1. 내 컴퓨터에서 먼저 돌려보기

Node.js 18 이상이 필요해.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 열면 **카톡 모양 시뮬레이터**가 나와.
오픈빌더 승인 전에도 이걸로 전체 흐름을 시연할 수 있어.

AI 분석까지 확인하려면 API 키를 넣고 실행해.

```bash
ANTHROPIC_API_KEY=sk-ant-... npm start
```

키가 없거나 AI 응답이 3.2초를 넘으면, 단어 기반 규칙으로 키워드를 대신 골라.
(카카오는 5초 안에 답이 안 오면 실패로 처리하기 때문)

---

## 2. 실제 카카오톡에 연결하기

전체 순서: **채널 만들기 → 오픈빌더 신청 → 서버 배포 → 스킬 연결 → 배포**

### ① 카카오톡 채널 만들기
- 카카오톡 채널 관리자센터(center-pf.kakao.com)에서 채널을 새로 만들어.
- 프로필 설정에서 **홈 공개**와 **검색 허용**을 켜줘.

### ② 카카오 i 오픈빌더 신청 (⚠️ 가장 먼저!)
- i.kakao.com 에서 오픈빌더 이용을 신청해. 채널 URL과 신청 사유를 적어야 해.
- **승인까지 며칠 걸릴 수 있으니 제일 먼저 신청해둬.**
  신청 사유에는 수업 프로젝트 목적과 서비스 내용을 구체적으로 적는 게 좋아.
- 승인되면 봇을 만들고, 설정에서 ①의 채널을 연결해.

### ③ 서버 배포 (예: Render)
카카오는 **https 주소**로만 스킬 서버를 부를 수 있어서, 서버를 인터넷에 올려야 해.

1. 이 폴더를 GitHub 저장소로 올리기
2. render.com → New → Web Service → 저장소 선택
3. Build Command: `npm install` / Start Command: `npm start`
4. Environment에 변수 추가
   - `ANTHROPIC_API_KEY` = 내 Claude API 키
   - `PUBLIC_BASE_URL` = Render가 준 주소 (예: `https://laika-signal.onrender.com`)
5. 배포 후 `https://내주소/health` 가 열리면 성공

> ⚠️ **무료 플랜 주의**
> - 한동안 접속이 없으면 서버가 잠들고, 깨어나는 데 수십 초가 걸려. 카카오는 5초를 못 기다리니 첫 메시지가 실패할 수 있어. **시연 직전에 `/health`를 한 번 열어 서버를 깨워두거나**, 시연 기간에만 유료 플랜을 쓰는 걸 추천해.
> - 서버가 다시 시작되면 쌓인 감상(`data/db.json`)이 사라질 수 있어. 예시 감상은 매번 다시 채워져. 실제 감상을 오래 보존해야 하면 디스크가 있는 플랜이나 데이터베이스로 옮겨야 해.

### ④ 오픈빌더에서 스킬 연결
1. **스킬** 메뉴 → 새 스킬 생성 → URL에 `https://내주소/skill` 입력 → 저장
2. **시나리오 → 폴백 블록**을 열고, 파라미터 설정에서 방금 만든 스킬을 선택
3. 봇 응답을 **스킬데이터 사용**으로 설정 → 저장
4. **웰컴 블록**도 똑같이 스킬을 연결 (채널에 처음 들어왔을 때 안내 메시지)
5. **배포** 버튼으로 배포

#### 상영 종료 안내와 신호가 알아서 오게 하려면 (콜백)
카톡 챗봇은 원래 바로 답해야 하는데, **콜백**을 켠 블록은 나중에 한 번 더 답할 수 있어(5분 안에 1번).
이걸로 '예매 안내 → 5초 뒤 상영 종료 안내', '우주로 보내기 → 30초 뒤 신호 도착'을 만들어.
1. **폴백 블록** 오른쪽 위 **더보기(…) → 콜백 설정**을 켜
2. 대기 메시지에 `{{#webhook.text}}` 를 넣어. 서버가 보내는 예매 안내·"신호를 보냈어요" 문구가 여기에 떠.
3. 파라미터 설정은 그대로(스킬 연결, 스킬데이터 사용) → 저장 → **배포**
- 설정에 콜백 메뉴가 안 보이면 **설정 → AI 챗봇 관리**에서 AI 챗봇 전환 신청이 필요할 수 있어.
- 콜백을 안 켜도 작동은 해. 그때는 관객이 다음에 말을 걸 때 상영 종료 안내나 신호가 도착해.
- 콜백은 봇 테스트 창에서는 제대로 안 될 수 있으니 **배포 후 실제 카톡에서** 테스트해.
- 폴백 블록에 콜백을 켰을 때 일반 답장이 이상하게 나오면, `우주로 보내기` 발화로 블록을 따로 만들어 그 블록에만 콜백을 켜는 방법도 있어.

#### 좋아요
받은 신호 카드마다 `♡ 좋아요` 버튼이 있어. 누르면 그 감상의 좋아요 수가 저장되고,
보낸 사람에게 "낯선 관객이 마음을 전했어요" 알림이 가(예시 감상은 제외).
좋아요 수는 `data/db.json`의 각 감상에 `likes`로 쌓여서, 나중에 반응 좋은 감상을 모아보는 데 쓸 수 있어.

#### 일상 속 신호 받기 (관객이 직접 체험)
한 바퀴가 끝나면 채팅 아래에 `📡 일상 속 신호 받기`와 `🎟 새로 예매하기`가 떠.
일상 속 신호 받기를 누를 때마다 "(며칠 뒤, 일상 속에서)"라는 말과 함께 신호가 도착해.
같은 영화의 비슷한 신호 → 다른 신호 → 내 신호에 좋아요 순서로 돌아가.
관객이 누르는 순간에 답하는 거라 **카톡에서도 바로 와.**

#### 운영자 패널 (일상 속 신호를 직접 보내보기)
`https://내주소/admin` 에서 관객 목록을 보고, 관객마다 버튼으로 신호를 보낼 수 있어.
- **비슷한 신호 / 다른 신호:** 그 관객이 마지막으로 본 영화의 감상 중 아직 안 받은 걸 골라서 보내
- **♥ 좋아요 받기:** 그 관객이 보낸 신호에 누군가 마음을 전한 것처럼 알림이 가
- 도착 시점은 지금 바로, 10초 뒤, 1분 뒤, 5분 뒤 중에서 고를 수 있어
- 쓰려면 Render 환경 변수에 **`ADMIN_KEY`**(운영자 비밀번호)를 정해두고, 패널에서 그 비밀번호를 입력해
- 시뮬레이터 관객은 몇 초 안에 바로 뜨고, 카카오톡 관객은 다음에 아무 말이나 보내면 도착해

#### 틈틈이 오는 알림에 대해
같은 영화에 새 신호가 들어오면 알림을 예약해둬.
- **시뮬레이터:** 실시간으로 도착해.
- **실제 카톡:** 관객이 다음에 말을 걸 때 먼저 보여줘.
- 카톡에서 챗봇이 먼저 메시지를 보내려면 **Event API**가 필요해. 비즈니스 인증 채널과 앱, 비즈월렛이 있어야 하고, 메시지 1건에 15원(VAT 별도)이 들어.

이렇게 하면 사용자가 보내는 모든 말이 서버로 오고, 대화 흐름은 서버가 알아서 처리해.
(블록을 여러 개 만들 필요 없음)

### ⑤ 테스트
- 오픈빌더의 봇 테스트 창이나, 채널을 친구 추가해서 카톡으로 직접 대화해봐.
- 아무 말이나 보내기 → 예매 안내 → 5초 뒤 상영 종료 안내 → 감상 입력 → `우주로 보내기` → 30초 뒤 신호 2개 도착

## 3. 바꿔 쓰는 곳

상영작, 키워드·문양, 대화 문구, 버튼 이름, 받는 신호 규칙, 신호 이미지 스타일은
전부 **`data/config.json` 한 파일**에 있어. 조정실 페이지에서 '변경사항 복사'로 받은
JSON을 이 파일에 그대로 덮어쓰면 반영돼. (서버 재시작 필요)

| 바꾸고 싶은 것 | 파일 |
|---|---|
| 위의 모든 설정 | `data/config.json` |
| 예시 감상 | `data/seed.json` |
| 대화 흐름 자체 (단계 추가 등) | `src/bot.js` |

### 환경 변수
| 이름 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 없음 | Claude API 키. 없으면 단어 규칙 사용 |
| `CLAUDE_MODEL` | `claude-haiku-5-5` | 빠른 모델 권장 (5초 제한) |
| `AI_TIMEOUT_MS` | `3200` | 이 시간이 넘으면 규칙으로 대체 |
| `PUBLIC_BASE_URL` | 요청 주소 | 문양 이미지 주소의 기준 (배포 시 꼭 설정) |
| `DELAY_STRANGER_MIN` | config 값 | 있으면 config의 '낯선 신호' 도착 시간을 덮어씀(분) |
| `DELAY_ECHO_MIN` | config 값 | 있으면 config의 '닮은 신호' 도착 시간을 덮어씀(분) |
| `NOTIFY_DELAY_MIN` | config 값 | 있으면 알림 예약 시간을 덮어씀(분) |
| `ADMIN_KEY` | 없음 | 운영자 패널(`/admin`) 비밀번호. 없으면 패널이 잠겨 있음 |
| `SHOW_SEED_LABEL` | config 값 | `false`면 예시 표시를 끔 |
| `DATA_DIR` | `./data` | 감상 저장 위치 |


---

## 4. 예시 감상에 대해
`data/seed.json`의 감상은 **시연을 위해 만든 예시**야. 카드에 '(예시)'가 붙어서 보여.
실제 관객에게 공개하기 전에는 팀원이나 지인에게 받은 **진짜 감상으로 바꿔두는 걸** 추천해.
그다음 `SHOW_SEED_LABEL=false` 로 꺼도 돼.

## 5. 구조

```
src/
  server.js    서버, /skill(카카오), /glyph/*.png(문양 이미지), 시뮬레이터
  bot.js       대화 흐름
  analyze.js   감상 → 키워드 (Claude, 실패 시 규칙)
  match.js     ② 낯선 신호 / ③ 닮은 신호 고르기
  glyph.js     키워드 → 도트 신호 PNG
  config.js    data/config.json 읽기
  keywords.js  키워드 목록
  store.js     JSON 저장소
public/index.html  카톡 모양 시뮬레이터
public/admin.html  운영자 패널
data/        config.json(모든 설정), 예시 감상, 저장된 감상(db.json)
```

### 매칭 규칙
- **낯선 신호**: 같은 영화 중, 키워드가 **딱 1개만 겹치고 나머지는 다른** 감상을 우선 골라.
  없으면 가장 덜 비슷한 감상. 전부 비슷하면 아직 도착하지 않은 것으로 두고 나중에 다시 찾아.
- **닮은 신호**: 다른 영화 중 키워드가 가장 많이 겹치는 감상.
- 다른 관객에게 보여주기 어려운 감상(욕설, 개인정보 등)은 AI가 걸러서 매칭에 쓰지 않아.
